# Older repo bridges — what actually carries forward

This is a correction to the tempting but too-neat reading of the Finnish repo names.

## AgainstTheGrain

Useful, but Gemini's mapping was not literal.

- `02_the_mirror_lies.py` is about a forward-trained predictor becoming actively harmful on a reversed **smooth trajectory**. It is not the 2026-08-07 endpoint-dose confound.
- `04_the_substrate_decides.py` compares reversal in a worn dissipative 1-D sequence with reversal in a toroidal coordinate manifold. It is not a prior demonstration that scalar morphology stores sequence order.

What transfers: **representation/substrate determines reversal cost**, and fixed passive geometry versus learned path-history must not be conflated.

## Nuoli — strongest direct bridge

Nuoli's failed 1-D flux was pure gauge. Only genuine plaquette/cycle flux changed the time-reversal symmetry class while preserving Hermiticity.

That is the exact caution needed for MorphogeneticNeuron: a scalar `M_A` whose gradient is interpreted as direction can be gauge-trivial or vanish when the scalar is uniform. Directed link variables and their loop sums are the correct local object.

## Ristikko + Kaiku

These repos are mainly **instrument lessons** for the current work.

- Different odd symmetries need the correct reference.
- Lagged self-reference can see a temporal arrow that intensity cannot.
- An external carrier/bias can silently make an otherwise blind readout directional.

Current consequence: centre the soma exactly, preserve mirror symmetry, use no hidden bias/reference in null arms, and calibrate the readout before interpreting a null.

## ArrowField + Eromitta

Two directly useful motifs:

- the skew/lag quantity is related to oriented energy/phase flux, which supports writing directed-link memory from local current rather than amplitude;
- gradient/frustration-sensitive media can pin and preserve structure much more strongly than intensity-sensitive media.

This suggests a future growth ablation: compare amplitude-gated, S-gated, current-gated, and phase-gradient/frustration-gated morphogenesis under identical opportunity fields.

## Vino

Vino says skew/antisymmetric recurrence is valuable for **long temporal order** in a fixed recurrent network. That remains distinct from the new `M_S` result:

- Vino: local recurrent operator carries direction.
- MGN `M_S`: a reciprocal body can encode order globally because its development is path-dependent.

These can coexist rather than compete.

## Tormays

Tormays' useful warning is that memory lives in non-contraction, and that a stray bias can act as a homodyne reference and fake directional readability.

For a grown dendrite, this points toward measuring whether loops/branches create persistent non-contracting delay modes rather than only measuring visual complexity.

## Alavirta — strongest bridge to the next build

Alavirta closed a predictive loop only after prediction and sensory evidence were rendered into the **same basis**, so a residual could actually be computed.

MorphogeneticNeuron currently has growth but weak credit assignment. The next functional version should use the soma/delay-space residual as a global modulatory signal on local branch eligibility. That is the missing bridge from "different shape" to "useful grown shape."

## Kolmijako

Mostly methodology here: validate the operator numerically, calibrate the meter on known symmetry classes/nulls, and never infer stability from a non-critical state. Its attitude is more reusable than its SU(2) result.
