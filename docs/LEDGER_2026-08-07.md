## The object

The project now separates two kinds of slow memory:

1. **`M_S` — reciprocal structural memory.** It changes positive symmetric link conductivity: where the body is, how thick paths are, and which global routes history has fossilised.
2. **`theta_x`, `theta_y` — directed-link memory.** It lives on oriented links. Reverse links carry the opposite sign. Its gauge-invariant observable is the plaquette/loop sum. It changes phase transport without pretending a scalar material density is itself a local arrow.

The fast state is a complex field `psi`.

The original v0.1 scalar `M_A` / gradient construction is retired as the main representation. A scalar can be useful as a stream function, but a nearly uniform scalar stores almost no local directed transport; its gradient is also vulnerable to being gauge-trivial. `Nuoli` already taught this lesson on a different problem.

## Finding A — a reciprocal morphology can encode temporal order globally

### Independent Claude implementation, user-run

After fixing two protocol confounds:

- **complete cycles only** — every patch receives the same number of training frames;
- **carrier reset on every visit** — patch identity is no longer tied to a particular carrier-phase epoch;

Claude's `write=S` arm reported, for 3 complete cycles:

```text
patch dose: [180, 180, 180, 180] in both directions
learned arrow  +0.03091
reported paired sigma +69.95
4/4 effects positive
unlearned bias +0.00066
```

The huge sigma is not the interesting number; seed/random-order spread remains the honest noise scale. The important observation is that the signed forward-vs-reverse preference survived removal of the dose and carrier-epoch confounds with `M_A = 0`.

### Interpretation

This does **not** mean a reciprocal medium has become locally nonreciprocal. It means the **plasticity maps do not have to commute**.

Let `F_i` be the slow morphology update caused by stimulus `i`. Even if each instantaneous transport operator is symmetric/time-even, nothing requires

```text
F_3 F_2 F_1 F_0(M) == F_1 F_2 F_3 F_0(M).
```

The first write changes the substrate on which the second write acts. Sequence order can therefore become a globally asymmetric fossil through ordinary path dependence / hysteresis / stigmergy.

Working term: **global order fossilisation** or **noncommuting morphogenesis**.

This does not contradict the old V13 reciprocity wall. V13 asks whether *fixed passive geometry generates directional transport*. This result asks whether *a history-dependent reciprocal geometry can end in different shapes under different event order*.

## Finding B — this repo directly measures the noncommutativity

`experiments/exp_noncommuting_growth.py` applies equal-dose A→B and B→A visits in the `symmetric` arm.

Small CPU audit used while building v0.2:

```text
size 48, dwell 12, repeats 2, 8 substrate seeds

with fast-field carry:
    mean normalized morphology commutator = 0.219600 ± 0.085816

reset psi/history before every visit, keep only the slow substrate:
    mean normalized morphology commutator = 0.081685 ± 0.085143

stimulus-blind growth null:
    exactly 0.0 for every seed
```

The first number contains both fast-state memory and structural path dependence.

The reset-fast arm is the sharper stigmergic result: the first structural write changes the material/opportunity field seen by the second write even when the fast wave and its history are erased between visits.

**Important limit:** this repo's strict four-patch root-energy probe has not yet reproduced Claude's functional `M_S` sequence preference. In a small N=64 / 4-seed smoke run, learned effect was about `-5e-5` against random-order spread `~1.9e-3`, despite a painted-asymmetry positive control being detectable. So in this implementation **order definitely changes morphology, but the changed morphology is not yet demonstrably useful to the current soma readout.**

That is not a contradiction. It says functional order memory is regime-dependent and gives us the next question: what makes the grown difference land on paths that matter to the soma?

## Finding C — directed links are the right place to test a local arrow

The old scalar `M_A` idea conflated a signed field with a directional coupling. `Nuoli` found in a separate gauge problem that a phase depending only on a scalar/1-D distance can be pure gauge, while non-removable loop flux requires genuine directed links/plaquettes.

v0.2 therefore stores:

```text
theta_x[y,x] : phase on (y,x) -> (y,x+1)
theta_y[y,x] : phase on (y,x) -> (y+1,x)
```

and reverse links automatically carry the conjugate phase.

The field operator is a Hermitian Peierls/covariant nearest-neighbour Laplacian. The gauge-invariant local diagnostic is the plaquette flux

```text
theta_x(top) + theta_y(right) - theta_x(bottom) - theta_y(left).
```

The links are written from local oriented phase current, not from generic activity magnitude.

### Independent Claude link-mode result, user-run

At `--arrow-mode link --mu-a 0.15 --chi 4`, 3 seeds:

```text
|M_A| / link memory      ~0.126
plaquette flux           ~0.104
learned total effect     -0.03192
read effect              -0.112
morphology/growth effect +0.005
transplant effect        -0.074
```

The important part is not the three-seed sigma. It is the causal decomposition: deleting the arrow at read time changes response strongly, transplanting it into another morphology carries the effect, while growth morphology changes little.

The sign opposed the `M_S` global fossil at that configuration. That produces the next sharp prediction: sweep `chi`; if the two channels are independent, the total sequence preference should pass through zero as the local link arrow cancels the global morphological fossil.

This repo's `experiments/exp_link_channel.py` implements the same question independently using `link_noread` training, delete tests, cross-transplants, and a `chi` sweep. Small CPU smoke tests show only a tiny link contribution so far; that is not a replication of Claude's magnitude.

## The architecture we now actually mean

```text
fast complex activity psi
        |
        +--> time-even / usage support ------> M_S reciprocal body
        |                                        |
        |                                        +--> changes future scalar conductivity
        |
        +--> oriented link current ----------> theta directed links
                                                 |
                                                 +--> changes future phase transport

M_S growth itself is path-dependent, so sequence can be stored globally even without theta.
theta is a second, local transport channel and must earn itself against M_S, not against zero.
```

The two memories are therefore **not** simply "S and A of one covariance copied into material." They live at different levels:

- `M_S`: global developmental history in reciprocal geometry;
- `theta`: local signed transport history on oriented edges/loops.

## What was fixed in v0.2

1. No mass-threshold stopping in the main order experiment. Training uses integer complete cycles.
2. Carrier phase resets at every patch visit.
3. Soma readout is a Gaussian centered on the exact half-integer geometric centre.
4. Explicit-Euler stability bound is checked at construction time.
5. Substrate disorder acts from t=0 on the whole conductivity and growth field; seed replicates genuinely differ.
6. Directed memory lives on links, not as a scalar whose gradient is later interpreted as an arrow.
7. Covariant links use conjugate reverse phases by construction.
8. Plaquette flux is measured directly.
9. Frozen-state delete/transplant tests replace approximate "sensitivity ceilings" when isolating directed memory.
10. A painted asymmetric morphology is used as a positive control for the order probe.

## What is not established

- The Claude `M_S` functional order result is low-n and has not yet reproduced in this independent implementation.
- A link-arrow effect has not been shown robust across grid size, dwell, damping, growth rate, and multiple implementations.
- No biological claim follows from either result.
- A dendrite-looking arbor is not automatically a useful delay computer.
- Fractal dimension is not the primary observable here.

## Next experiments, in order

### 1. Map the order-memory regime

Claude's system shows functional `M_S` order memory; this one currently shows structural noncommutativity but a null soma preference. Sweep the ratio between stimulus dwell and field relaxation/plasticity timescale.

Prediction: if every stimulus fully equilibrates before the next, order fossilisation should shrink. It should grow in the hysteretic regime where the next stimulus meets a still-changing fast/slow state.

### 2. Directed-link `chi` sweep with frozen transplants

Train `link_noread`, freeze, and sweep `chi = 0,1,2,3,4,6` without retraining.

Measure separately:

```text
same morphology, links deleted
same morphology, links read
links transplanted to opposite morphology
```

The local channel is real only if its contribution reverses with training order, has low bias, survives transplant, and remains signed across configurations.

### 3. Make growth useful, not merely different

Use the old `Alavirta` seam: a global soma/prediction residual in the same delay-space basis should modulate a local eligibility trace. In biological language this is a three-factor plasticity rule; in the original PerceptionLab language it restores the homeostatic feedback that made the ECG-like pulse in the first place.

Candidate rule:

```text
local eligibility = phase current / coincidence on a branch
slow write         = eligibility * global soma residual or resonance error
```

Then branches are selected because they improve a function at the soma, not because they merely lie on a locally busy field.

### 4. Only then grow the 3-D dendrite

The 3-D build should be judged by function first:

- sequence recognition after growth is frozen;
- path-delay distribution;
- response to reversed order;
- lesion/re-growth recovery;
- whether multi-timescale drives grow a broader bank of delays.

If it also looks like a dendritic arbor, that becomes meaningful rather than decorative.
